# Fishers Dent Repair Guide — agent instructions

This repository is the pilot for a repeatable, policy-conscious local lead website engine.

## Non-negotiable claims policy
- Never state or imply that this website owns a repair shop, has a Fishers storefront, employs technicians, or directly performs repairs.
- Never invent addresses, opening hours, certifications, provider counts, response times, prices, reviews, ratings, testimonials, insurance relationships, before/after results, or warranties.
- Describe the site as an independent consumer information and provider-matching service.
- Any new city or service page must add substantial original value; do not create keyword-swapped doorway pages.
- Structured data must match visible page content. Do not add `LocalBusiness`, `AggregateRating`, or fabricated service offers.

## Conversion and privacy
- Keep lead-sharing disclosure adjacent to every form.
- Consent must be affirmative and unbundled from unrelated marketing.
- Route a request to no more than one provider unless the user explicitly agrees otherwise.
- Do not enable call recording without a clear prerecorded disclosure.
- Replace placeholder domain, phone, form endpoint, and operator contact details before production launch.

## SEO quality bar
- Preserve crawlable server-rendered content, semantic headings, canonical site URLs, sitemap, robots rules, and `llms.txt`.
- Optimize for usefulness, accessibility, and mobile speed before adding pages.
- Cite authoritative sources when publishing factual local, insurance, legal, or safety claims.
